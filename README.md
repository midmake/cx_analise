# Análise de Mercado — Caixeiros Viajantes

Dashboard de inteligência de mercado desenvolvido e mantido por **Rafael Bortolin — Assistente Administrativo**.

## Regra histórica dos dados
- **Pesquisa 2024:** valores-base de **2023**.
- **Pesquisa 2025:** valores-base de **2024**.
- **Pesquisa 2026:** valores atuais e vigentes de **2026**.

O dashboard separa o **ano dos valores** do **ano da pesquisa de origem**. Valores ainda não confirmados não são estimados: aparecem como **“Aguardando dados do Administrativo — Setor de Esportes”**.

A interface inclui filtros, visão executiva compacta, tabela-resumo, benchmark entre clubes, evolução histórica, fontes e pendências de contato.
